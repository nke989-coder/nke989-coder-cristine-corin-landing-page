# Cristine Corin — Landing page

Base do projeto para desenvolvimento iterativo de uma landing page premium, com a identidade visual original da cliente.

## Estado atual

- 10 anexos recuperados e preservados sem edição: 2 logos, 7 fotos e 1 paleta.
- Cards do Protocolo Essência: aguardando envio; não estavam entre os anexos recuperados.
- Repositório remoto público criado: https://github.com/nke989-coder/nke989-coder-cristine-corin-landing-page
- Estrutura de pastas e dados confirmados preparados; aplicação e tecnologia ainda não definidas.
- Sem publicação ou deploy nesta etapa.

## Organização

- `assets/originals/`: materiais recebidos, com nomes originais e conteúdo intacto.
- `docs/assets-manifest.json`: inventário, tamanho e SHA-256 de cada arquivo.
- `src/content/profissional.json`: dados confirmados, independentes da tecnologia escolhida.
- `src/components/` e `src/styles/`: reservados para o desenvolvimento.
- `public/`: reservado para arquivos efetivamente usados no site.

Não redesenhar, recolorir, vetorizar ou substituir as logos. Não sobrescrever os originais ao produzir versões para a web. A imagem da paleta é a referência: códigos de cor ainda não foram extraídos ou aprovados. Não inventar credenciais, depoimentos, resultados, serviços ou detalhes do protocolo.
